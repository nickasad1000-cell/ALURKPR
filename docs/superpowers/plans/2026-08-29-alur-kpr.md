# ALUR KPR Implementation Plan

> Eksekusi: inline di sesi ini (user: "kerjakan semua sampai selesai"). Steps pakai checkbox.

**Goal:** Website edukasi alur KPR (Syahfalah Group) — one-page journey + tools (kalkulator, cek subsidi, checklist dokumen), bold editorial premium, data bunga real dari Supabase (read-only + fallback lokal).

**Architecture:** Next.js 15 App Router (TS) + Tailwind v4; konten tahapan sebagai data TS di `content/`; GSAP pinned timeline di homepage; Supabase ISR (3600s) dengan fallback seed; checklist via localStorage; vitest untuk logika uang.

**Tech Stack:** next@15, react@19, tailwindcss@4, gsap, lenis, framer-motion, lucide-react, @supabase/supabase-js, vitest, sharp.

## Global Constraints

- Bahasa UI: Indonesia. `lang="id"`.
- Token warna: paper `#F7F4EE`, ink `#14171B`, accent `#0B6B4F`, gold `#C99A3C`, danger `#B4443C`.
- Font: Fraunces (display) + Plus Jakarta Sans (body), via `next/font/google`, self-host.
- Tidak ada secrets di git. `.env.local` gitignored; commit hanya `.env.example`.
- Gate rilis: `npm run test` + `lint` + `build` hijau.
- Vercel project: `kpr` (fallback `kprsubsidi`). Supabase opsional (fallback seed).

### Task 2: `lib/finance.ts` + tests (TDD)

**Interfaces consumed everywhere:** `angsuranBulanan(plafon:number, rateYearlyPct:number, tenorYears:number):number`; `jadwalAmortisasi(...): {bulan,pokok,bunga,saldo}[]`; `biayaAwal(harga, dpPct): {dp, provisi, admin, bphtb, notaris, asuransi, total}`; `plafondMaksimal(harga, dpPct):number`.

- [ ] Test: anuitas 300jt, 5%, 20th → angsuran ≈ 1.979.867 (±1000). Suku 0% → harga/tenor. DP 20% dari 300jt → plafon 240jt. Biaya awal = penjumlahan benar.
- [ ] Implement: `P * r/12`, annuity factor `r(1+r)^n / ((1+r)^n - 1)`. Pembulatan rupiah.
- [ ] `npx vitest run` hijau → commit `feat(lib): finance math + tests`.

### Task 3: `lib/eligibility.ts` + tests
