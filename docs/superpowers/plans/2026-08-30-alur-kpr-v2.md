## 5. FITUR BARU — Wizard Demografis Interaktif "Profil Kamu" (permintaan user)

### 5.1 Tujuan & Posisi
Alat personalisasi #1: "Kamu siapa?" → saran jalur KPR + kisaran harga terjangkau + angsuran realistis + **langkah pertama yang dimandatkan**. Ini *activation event*: mengubah visitor pasif jadi tersegmentasi, dan titik lead capture pertama. **Membedakan dari kompetitor** & magnet keyword "kpr cocok untuk saya".

### 5.2 Route & Struktur
- Route: `/profil-kamu` (Server Component) + `components/profil-wizard.tsx` (`"use client"`) + `lib/rekomendasi.ts` (logika murni, ter-test) + `content/rekomendasi.ts` (aturan konten).
- `app/profil-kamu/page.tsx` server: ketik + metadata + JSON-LD (opsional) + render `<ProfilWizard rates={await getBankRates()} />`.

### 5.3 Langkah Wizard (6 pertanyaan bertahap, progress bar, bisa back)
1. **Umur** — range: `<25`, `25–30`, `31–40`, `>40` (mempengaruhi tenor maks & kelayakan subsidi).
2. **Status & tanggungan** — lajang / menikah (0–1–2+ anak). (Batas penghasilan rumah tangga untuk FLPP.)
3. **Penghasilan rumah tangga/bulan** — slider + input (id-ID), + pekerjaan (karyawan tetap / kontrak / wiraswasta / freelancer) — mempengaruhi dokumen yang dibutuhkan & skema.
4. **Status tempat tinggal saat ini** — belum punya rumah (target FLPP) / sudah punya rumah sendiri / tinggal dgn orang tua (komersial/upgrade).
5. **Pernah terima subsidi KPR?** — ya / tidak.
6. **Lokasi/kota sasaran** *(opsional)* — untuk plafon subsidi zona (166jt–240jt) & estimasi biaya notaris regional.

### 5.4 Output — Kartu Hasil "ProfilKamu"
- **Jalur rekomendasi:** `Subsidi FLPP` / `Komersial` / `Syariah` / `Cek dulu ke bank` dengan alasan ringkas (reuse `cekKelayakan()` dari `lib/eligibility.ts` + aturan baru).
- **Kisaran harga rumah terjangkau:** rasio cicilan 30–35% penghasilan → rentang harga (reuse `plafondMaksimal`/`angsuranBulanan`).
- **Estimasi angsuran** untuk harga tengah + tenor yang disarankan.
- **Langkah pertama dipersonalisasi** (daftar dari `content/tahap.ts` yang relevan statusnya — e.g. belum punya rumah → mulai tahap-1 kelayakan).
- **CTA next-step:** "Hitung angsuranmu" → `/kalkulator?harga=X&dp=Y&tenor=Z` (prefill), "Cek kelayakan" → `/syarat`, "Konsultasi via WhatsApp" → `wa.me`.
- **Persistensi:** simpan jawaban ke `localStorage` (key `kpr:profil`) → bewelcome/revive via banner "Lanjutkan profilmu".
- **Lead capture (opt-in):** input email opsional → simpan ke Supabase `leads` (baru) + UU PDP consent checkbox.

### 5.5 Aksesibilitas wizard (dari audit)
- H1 di halaman (`as="h1"`), tiap langkah `role="group"` + `aria-labelledby`, progress bar `aria-valuemin/max/now`, hasil `role="status"` + `aria-live`, tombol back/next fokus kena Escape, semua slider `aria-valuetext`, input `name`+`autocomplete`.

### 5.6 Logika & Tests
- `lib/rekomendasi.ts`: `rekomendasi(input: ProfilInput): ProfilHasil` murni. Test: tiap kombinasi jalur → alasan & rentang harga benar; tidak layak subsidi karena penghasilan/tanggungan/rumah/subsidi → alasan muncul; ≥1 langkah pertama selalu keluar; angka mengikuti `finance.ts`.
- `npm run test` + `build` hijau.
